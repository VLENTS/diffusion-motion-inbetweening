# 从视频中选取最优关键帧的策略

## 0. 问题定义

**输入**：一段视频 + 3DGS 渲染管线提取的粗动作序列 + 对应的 3D 场景
**输出**：一组关键帧集合 $\mathcal{K} = \{(t_i, \mathbf{x}_i)\}_{i=1}^k$，用于下游 motion in-betweening
**目标**：选出的关键帧同时满足语义完整性和过渡安全性，使下游补全质量最高

---

## 1. 关键帧需要满足的两个前提

### 前提 1：语义不退化

关键帧集合必须覆盖原始动作的所有语义转折点。如果漏掉了"坐下"的瞬间，in-betweening 模型会直接从"站着"插值到"坐着"，中间过渡不自然。

### 前提 2：过渡路径可行

相邻关键帧之间的空间-时间关系必须合理：距离不能太远（否则过渡需要不自然的快速运动），中间不能有密集障碍物（否则过渡路径必须大幅绕行），姿态变化不能太剧烈（否则过渡不连贯）。

---

## 2. 语义保持：怎么选帧才不丢语义

### 2.1 动画师的关键帧选择原则

动画制作中，关键帧（Keys）有严格的层级定义 [Keys, Breakdowns & In-betweens, drawntoanimation.com]：

- **Key Poses**：定义动作的核心姿态——情绪、时机、态度的锚点。由主动画师绘制。
- **Breakdowns**：两个 Key Pose 之间的过渡姿态，定义运动轨迹和节奏。
- **In-betweens**：填充所有剩余帧，创造平滑运动。

**核心原则**：Key Pose 是动作的"极端姿态"（extreme poses）——速度为零的转折点（如手臂抬到最高点、脚着地的瞬间）。选取 Key Pose 就是选取运动轨迹中的**局部极值点**。

映射到你的场景：从视频中提取的动作序列，关键帧应该选在**姿态变化率的峰值或谷值处**——即运动最剧烈或停顿的时刻。

### 2.2 方法 A：基于 2D 关键点的运动分析选帧

利用视频中的 2D 关键点轨迹，检测语义转折点：

**步骤**：
1. 用 2D pose estimator（如 ViTPose、RTMPose）提取每帧的 2D 关键点 $\mathbf{p}_t \in \mathbb{R}^{J \times 2}$
2. 计算帧间变化率：$\Delta_t = \|\mathbf{p}_{t+1} - \mathbf{p}_t\|_2$
3. 检测 $\Delta_t$ 的**峰值**（运动最剧烈的帧 = breakdown 帧）和**谷值**（运动停顿的帧 = key pose）
4. 取所有峰值和谷值帧作为候选关键帧

**优势**：
- 纯 2D 操作，不依赖 3D 重建质量
- 运动分析可以在视频预处理阶段完成，零额外成本
- 基于 Keypoint-MoSeq [Nature Methods, 2024] 的发现：关键点动态的自然不连续点对应行为转折

**相关工作**：
- **Keypoint-MoSeq** [Nature Methods, 2024]：从 2D 关键点轨迹中解析连续动作为离散行为单元（syllables），通过检测姿态动态的不连续点识别动作边界
- **DyBDet** [2024]：动态网络检测视频中的通用事件边界，区分低级外观变化和高级语义变化

### 2.3 方法 B：基于 CLIP 的语义匹配选帧

利用 CLIP 对每帧与文本描述的匹配度进行打分：

**步骤**：
1. 对视频的每一帧 $I_t$，计算 CLIP 匹配分数 $s_t = \text{CLIP}(I_t, \text{text\_prompt})$
2. 对候选关键帧集合 $\mathcal{K}$，计算平均匹配分数 $\bar{s}_\mathcal{K} = \frac{1}{|\mathcal{K}|} \sum_{t_i \in \mathcal{K}} s_{t_i}$
3. 设置阈值 $\tau$：要求 $\bar{s}_\mathcal{K} \geq \tau$
4. 如果不满足，增加关键帧（优先添加 $s_t$ 高但当前不在 $\mathcal{K}$ 中的帧）

**阈值设定**：$\tau$ 可以设为全帧 CLIP 分数均值的某个比例，如 $\tau = 0.95 \times \bar{s}_{\text{all}}$，表示关键帧的语义覆盖不低于全帧的 95%。

**相关工作**：
- **KeyScore** [2024]：结合语义相似度、时间代表性、上下文影响三个信号的帧评分方法，可在 99% 帧减少率下保持性能
- **TiFRe** [2024]：用 CLIP 风格的 prompt 计算文本-帧语义相似度选取关键帧，含 Frame Matching and Merging 机制保留非关键帧信息
- **AKS** [Adaptive Keyframe Sampling]：将关键帧选择形式化为优化问题，平衡关键帧-prompt 相关性和视频覆盖度

### 2.4 方法 C：多模态大模型辅助选帧

利用 MLLM（如 GPT-4o、Qwen-VL）理解视频内容，直接输出关键帧建议：

**步骤**：
1. 将视频（或均匀采样的帧序列）输入 MLLM
2. Prompt 示例：*"这段视频展示了一个人在室内场景中的动作。请识别动作中的关键姿态转折点，输出这些转折点对应的帧编号。关键姿态包括：动作开始、动作结束、姿态变化最大的时刻、与场景物体发生交互的时刻。"*
3. MLLM 返回关键帧候选列表
4. 用方法 A/B 的定量指标验证和补充

**优势**：
- 可以理解高层语义（"人在准备坐下" vs "人在弯腰捡东西"）
- 可以识别场景交互的关键时刻（手接触物体、脚接触地面）
- 无需手工设计规则

**相关工作**：
- **HiMu** [2026]：将查询分解为层级逻辑树，路由到轻量多模态专家（CLIP、目标检测、OCR），仅用 16 帧即可超过使用 32-512 帧的竞争方法
- **FOCUS** [2025]：将关键帧选择形式化为多臂赌博机的组合纯探索问题，通过置信区间识别信息丰富的时间区域
- **VideoITG** [2025]：基于用户指令自适应定制帧采样策略，利用 Video-LLM 的视觉-语言对齐做判别式帧选择

## 3. 过渡安全性：怎么保证相邻关键帧之间的路径不绕远

### 3.1 从原始视频层面判断（2D 层面）

不依赖 3D 重建质量，直接在视频上判断：

**方法 D：2D 关键点轨迹平滑度检测**

1. 提取 2D 关键点轨迹 $\mathbf{p}_t \in \mathbb{R}^{J \times 2}$
2. 对相邻关键帧 $(t_i, t_j)$ 之间的轨迹段，计算：
   - **轨迹弯曲度**：实际轨迹长度 / 直线距离（= 1 时是直线，越大越绕）
   - **速度均匀度**：帧间速度的方差（方差大说明有急停急走，过渡不自然）
   - **2D 遮挡率**：人体关键点在这段时间内的检测置信度均值（低置信度 = 遮挡 = 可能有复杂场景交互）
3. 如果弯曲度 > 阈值 或 速度方差 > 阈值，在中间插入更多关键帧

**优势**：纯 2D，零 3D 依赖，可以在 3DGS 重建之前就完成关键帧初选。

### 3.2 从提取的 3D 动作层面判断

利用 3DGS 管线提取的 3D 动作和场景：

**方法 E：速度可行性检查**

$$v_{ij} = \frac{\|\mathbf{x}_{t_i}^{\text{root}} - \mathbf{x}_{t_j}^{\text{root}}\|_2}{(t_j - t_i) \cdot \text{dt}}$$

设训练数据中的最大合理速度为 $v_{\max}$（走路 ~1.5 m/s，跑步 ~3 m/s）。若 $v_{ij} > v_{\max}$，说明间距太大或时间太短，需要在中间加关键帧。

**方法 F：直线路径穿透检测**

对相邻关键帧 $(t_i, t_j)$，检查根节点之间的直线路径是否穿过场景 mesh：

1. 从 $\mathbf{x}_{t_i}^{\text{root}}$ 到 $\mathbf{x}_{t_j}^{\text{root}}$ 做射线检测（ray casting）
2. 如果与场景 mesh 有交点，标记这对关键帧之间"有障碍物"
3. 在障碍物位置附近插入关键帧，强制过渡路径绕行

**方法 G：姿态兼容性检查**

$$d_{\text{pose}}(t_i, t_j) = \frac{1}{K} \sum_{k=1}^{K} \left\lVert \hat{\mathbf{J}}_{t_i,k} - \hat{\mathbf{J}}_{t_j,k} \right\rVert_2$$

（根节点对齐后的关节位置差异）

如果 $d_{\text{pose}} > \theta_{\text{pose}}$，说明两帧的姿态差异太大（如从站姿到躺姿），需要在中间加过渡关键帧。阈值 $\theta_{\text{pose}}$ 可以从训练数据中统计得到。

**方法 H：场景占据密度检查**

在两个关键帧根节点之间的包围盒内，计算场景 mesh 的体素占据率：

$$\rho_{ij} = \frac{\text{被占据的体素数}}{\text{总体素数}} \bigg|_{\text{bbox}(\mathbf{x}_{t_i}^{\text{root}}, \mathbf{x}_{t_j}^{\text{root}})}$$

占据率越高，过渡路径需要绕行的可能性越大，应在中间加密关键帧。

## 4. 综合选帧策略

### 4.1 两阶段选帧流程

```
阶段 1：视频层面初选（不依赖 3D 重建）
  ├─ 方法 A：2D 关键点运动分析 → 检测语义转折帧
  ├─ 方法 B：CLIP 语义匹配 → 过滤低语义帧
  ├─ 方法 C：MLLM 辅助 → 识别高层语义转折
  └─ 方法 D：2D 轨迹平滑度 → 标记路径复杂区域
  输出：候选关键帧集合 K_cand + 需要加密的区域标记

阶段 2：3D 动作层面精选（依赖提取的动作和场景）
  ├─ 方法 E：速度可行性 → 过滤间距过大的相邻帧
  ├─ 方法 F：直线穿透检测 → 在障碍物处加密
  ├─ 方法 G：姿态兼容性 → 在姿态突变处加密
  └─ 方法 H：场景占据密度 → 在密集区域加密
  输出：最终关键帧集合 K_final
```

### 4.2 形式化：关键帧选择的优化目标

将关键帧选择形式化为一个受约束的优化问题：

$$\mathcal{K}^* = \arg\min_{\mathcal{K}} |\mathcal{K}| \quad \text{（最小化关键帧数量）}$$

$$\text{s.t.} \begin{cases} \bar{s}_\mathcal{K} \geq \tau_{\text{sem}} & \text{（语义覆盖约束）} \\ v_{ij} \leq v_{\max}, \; \forall (t_i, t_j) \text{ adjacent in } \mathcal{K} & \text{（速度可行性）} \\ \text{ray}(\mathbf{x}_{t_i}^{\text{root}}, \mathbf{x}_{t_j}^{\text{root}}) \cap \mathcal{G} = \emptyset, \; \forall (t_i, t_j) & \text{（路径无穿透）} \\ d_{\text{pose}}(t_i, t_j) \leq \theta_{\text{pose}}, \; \forall (t_i, t_j) & \text{（姿态兼容性）} \\ t_1 = 1, \; t_k = T & \text{（必含首尾帧）} \end{cases}$$

其中 $\bar{s}_\mathcal{K}$ 为 CLIP 平均匹配分数，$\mathcal{G}$ 为场景几何，$T$ 为总帧数。

目标是在满足所有约束的前提下，用**最少的关键帧**覆盖整个序列——关键帧越少，模型的生成自由度越大，但过少会违反约束。

### 4.3 贪心求解算法

上述优化问题是 NP-hard 的（类似最小集合覆盖），可用贪心策略近似求解：

```
输入：全帧序列 {1, ..., T}，约束函数集
输出：关键帧集合 K

1. 初始化 K = {1, T}  // 强制包含首尾帧
2. 计算所有相邻关键帧对的约束违反情况
3. while 存在违反约束的相邻对 (t_i, t_j):
     a. 找到违反程度最严重的对 (t_i*, t_j*)
     b. 在 [t_i*, t_j*] 中间选择最优插入帧 t_new:
        - 方法 A 的运动峰值帧优先
        - 其次选 CLIP 分数最高的帧
        - 其次选中点 (t_i* + t_j*) / 2
     c. K = K ∪ {t_new}
     d. 重新计算约束违反情况
4. return K
```

### 4.4 MLLM 辅助的集成方案

将 MLLM 作为初选器，定量方法作为验证和补充：

```
1. MLLM 初选：
   输入视频 → MLLM 输出候选关键帧列表 + 理由
   （利用 MLLM 的高层语义理解能力）

2. 定量验证：
   对 MLLM 输出的候选帧，用方法 A-H 逐一检查约束
   标记不满足的约束

3. 自动补充：
   对不满足约束的区域，用贪心算法插入额外关键帧

4. MLLM 复核（可选）：
   将补充后的关键帧集合回传 MLLM
   让 MLLM 确认"这组关键帧是否覆盖了所有关键动作"
```
